# 터랄 (turlal)
<img width="1320" height="526" alt="image" src="https://github.com/user-attachments/assets/9d441749-9560-4f4c-8596-63a4dfeb4b2a" />

Turlal은 파이썬 위에서 실행되는 한글 밈 기반 프로그래밍 언어입니다. 터랄 코드를 파이썬 코드로 바꾼 뒤 실행하므로, 기본 문법은 간단하게 쓰고 필요한 기능은 원래 파이썬도 함께 쓸 수 있습니다.

```turlal
마그마 "Hello, Turlal" 올리자
등신 애쓴다 ㅋㅋ
```

실행 결과:

```text
Hello, Turlal
```

## 시작하기

### 1. 준비물

Windows에서는 Python 3.10 이상이 필요합니다. [Python 공식 사이트](https://www.python.org/downloads/)에서 설치할 때 **Add Python to PATH** 옵션을 켜세요.

설치가 끝난 뒤 터미널에서 아래 명령이 동작하는지 확인합니다.

```powershell
py --version
```

`py`가 없다면 `python --version`을 사용해도 됩니다.

### 2. 프로젝트 열기

이 폴더를 VS Code로 엽니다. VS Code 확장 탭에서 Microsoft의 **Python** 확장을 설치하면 터미널 실행과 디버깅이 편해집니다.

```text
turlal/
├── turlal.py          # 터랄 실행기
├── example.turlal     # 실행해 볼 예제
├── test_turlal.py     # 자동 테스트
└── README.md
```

### 3. 예제 실행하기

VS Code에서 ``Ctrl+` ``로 터미널을 열고 아래 명령을 실행합니다.

```powershell
py .\turlal.py run .\example.turlal
```

`12`, 조건문 결과, `0`부터 `6`까지의 반복 결과 등이 출력되면 정상입니다.

## 첫 프로그램 만들기

1. 프로젝트 폴더에 `main.turlal` 파일을 만듭니다.
2. 아래 코드를 붙여 넣습니다.
3. 마지막 줄의 `등신 애쓴다 ㅋㅋ`를 반드시 넣습니다.

```turlal
터틀 나이는 205
마그마 터틀 올리자

등신 애쓴다 ㅋㅋ
```

아래 명령어로 실행합니다.

```powershell
py .\turlal.py run .\main.turlal
```

## 핵심 규칙

### 수

터랄 문법 영역에서는 숫자 리터럴에 `0`, `2`, `5`만 사용할 수 있습니다.

```turlal
터틀방송 나이는 (2*2+2)/(2*2)
작년터틀 나이는 205-2/2

등신 애쓴다 ㅋㅋ
```


### 변수와 출력

`나이는`은 값을 저장하는 기호이고, `마그마 ... 올리자`는 화면에 출력하는 문장입니다.

```turlal
터틀 나이는 205
마그마 터틀 올리자

등신 애쓴다 ㅋㅋ
```

### 조건문

`!!`은 파이썬의 `:` 역할입니다. 조건에 속한 코드는 반드시 들여쓰기 해야합니다.

```turlal
가니쉬 나이는 2

야 가니쉬 > 19 아니잖아!!
    마그마 "통과" 올리자
아니 야 점수 == 19 아니잖아!!
    마그마 "이건 어떻게 되는거지?" 올리자
아니!!
    마그마 "미자니쉬" 올리자

등신 애쓴다 ㅋㅋ
```

### 반복문

`정병 조건 동안!!`은 조건이 참인 동안 반복합니다. 터랄에는 아쉽게도 `for` 문이 없습니다.

```turlal
횟수 나이는 0

정병 횟수 < 2+5 동안!!
    마그마 횟수 올리자
    횟수 나이는 횟수 + 2

등신 애쓴다 ㅋㅋ
```

### 함수

함수는 `터랄`, 반환은 `터바`를 사용합니다.

```turlal
터랄 더하기(왼쪽, 오른쪽) 은 내가 만든 말이야!!
    터바 왼쪽 + 오른쪽

결과 나이는 더하기(2, 5)
마그마 결과 올리자

등신 애쓴다 ㅋㅋ
```

### 파이썬 라이브러리 가져오기

```turlal
터하 math 틀하 수학
마그마 수학.sqrt(2+2+5) 올리자

등신 애쓴다 ㅋㅋ
```

`터하 라이브러리 틀하 별칭`은 `import 라이브러리 as 별칭`으로 변환됩니다. 별칭은 생략할 수 있습니다.

```turlal
터하 random
스하 datetime 터하 *

등신 애쓴다 ㅋㅋ
```

### 원래 파이썬 문법 사용하기

터랄에 없는 문법이나 복잡한 라이브러리 API는 
`아싸리 ~ 는 내가 만든 말이 야니야` 블록 안에 일반 파이썬으로 작성합니다.

```turlal
아싸리
numbers = [1, 2, 3]
print(sum(numbers))
는 내가 만든 말이 아니야

등신 애쓴다 ㅋㅋ
```

## 파이썬으로 변환해서 보기

터랄이 어떤 파이썬으로 바뀌는지 확인하려면:

```powershell
py .\turlal.py transpile .\main.turlal
```

파일로 저장하려면:

```powershell
py .\turlal.py transpile .\main.turlal -o .\main.py
```

## 오류가 났을 때

| 메시지 | 해결 방법 |
| --- | --- |
| `숫자 리터럴 ... 0, 2, 5만` | `7` 대신 `2+5`처럼 계산식으로 작성합니다. |
| `스크립트 마지막 줄은 ...` | 파일의 마지막 줄에 `등신 애쓴다 ㅋㅋ`를 추가합니다. |
| `알 수 없는 터랄 문장` | 아직 지원하지 않는 문법입니다. `아싸리` 블록 안에 파이썬으로 작성합니다. |
| `블록이 ... 닫히지 않았습니다` | `아싸리`를 열었다면 `는 내가만든 말이 아니야`로 닫습니다. |
